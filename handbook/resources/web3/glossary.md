# Web3 Glossary

- **Blockchain:** A distributed ledger maintained by a network of participants.
- **Block:** A batch of transactions or records added to a blockchain.
- **Consensus:** The mechanism participants use to agree on blockchain state.
- **dApp:** A decentralized application that interacts with blockchain infrastructure.
- **DAO:** A community-governed organization coordinated through blockchain-based rules.
- **DeFi:** Financial applications and protocols built using decentralized infrastructure.
- **Gas:** The computational fee paid for blockchain transactions.
- **Layer 2:** A scaling system built on top of a base blockchain.
- **Mainnet:** A production blockchain network.
- **NFT:** A non-fungible token representing a unique digital or physical asset.
- **Private Key:** A secret used to authorize blockchain transactions.
- **Smart Contract:** Program code deployed on a blockchain that executes defined rules.
- **Stablecoin:** A token designed to maintain a relatively stable value.
- **Testnet:** A blockchain network used for testing before production deployment.
- **Tokenomics:** The economic model governing a token.
- **Validator:** A participant that helps verify and finalize blockchain transactions.
- **Web3:** A broad term for decentralized, user-owned internet applications.
- **ZK Proof:** A cryptographic proof that can establish a claim without revealing the underlying secret.
