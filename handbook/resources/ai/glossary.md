# AI Glossary

- **AI:** Systems that perform tasks associated with human intelligence.
- **Agent:** An AI system that can reason, use tools, and take actions toward a goal.
- **ANN:** Artificial Neural Network.
- **Backpropagation:** A method used to calculate gradients for neural-network training.
- **Computer Vision:** AI techniques for understanding images and video.
- **Dataset:** A collection of data used for training, validation, or testing.
- **Deep Learning:** Machine learning based on multi-layer neural networks.
- **Embedding:** A numerical representation of data that captures semantic relationships.
- **Fine-tuning:** Adapting a pretrained model to a specific task or dataset.
- **Generative AI:** AI that generates content such as text, images, audio, or code.
- **LLM:** Large Language Model, a model trained on large text datasets for language tasks.
- **Machine Learning:** Methods that enable systems to learn patterns from data.
- **Multimodal AI:** AI that works with multiple modalities such as text, images, audio, or video.
- **NLP:** Natural Language Processing.
- **Overfitting:** When a model learns training data too closely and generalizes poorly.
- **Prompt:** Instructions or context supplied to an AI model.
- **RAG:** Retrieval-Augmented Generation, combining retrieval with generation.
- **Token:** A unit of text processed by a language model.
- **Transformer:** A neural-network architecture widely used for modern language and multimodal models.
