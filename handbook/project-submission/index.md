# Project Submission — 2026–27

Submission requirements vary by HackIndia event. The **event page and official submission instructions always take priority**.

## Recommended Submission Checklist

### 1. Source Code
Publish the project in a GitHub repository when the event requires it.

Your repository should contain:
- Clear project name
- README
- Installation/setup instructions
- Architecture or system overview
- Source code
- Environment-variable example without exposing secrets
- Demo instructions

### 2. Working Demo

Provide a working prototype, live deployment, or demonstrable workflow as required by your event.

Test the demo before submission.

### 3. Demo Video

If your event requires a video, keep it focused:
1. Problem
2. Product
3. Key feature
4. Live demonstration
5. Technology
6. Impact

### 4. Project Description

Explain:
- Problem statement
- Target users
- Solution
- Key features
- Technology stack
- Architecture
- Innovation
- Impact
- Future scope

### 5. Submission Links

Before clicking submit, verify every URL:
- GitHub repository
- Live demo
- Demo video
- Pitch deck, if required
- Any sponsor-track submission form

## Security Checklist

Never publish:
- API keys
- Passwords
- Access tokens
- Private certificates
- Production database credentials
- Personal secrets

Use environment variables and provide a `.env.example` file instead.

## Final Check

**Code ✓ Demo ✓ README ✓ Video ✓ Pitch ✓ Links ✓ Team details ✓**

Submit early enough to recover from upload or deployment issues.
